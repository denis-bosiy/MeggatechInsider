# Фронтенд-часть проекта MeggatechInsider

Используе(ю)тся:
- Транскомпилятор Typescript
- Препроцессор SASS
- Линтеры: ESLint, Stylelint
- Автоформаттер Prettier

Необходимо установить расширения ESLint, Prettier в VS Code, если используется эта IDE

## Доступные скрипты

### `npm run start`

Запуск проекта на localhost:3000 вместе с Stylelint watcher(проверка стилей линтером в режиме реального времени)
Сообщения от линтера будут выводиться в консоль

### `npm run build`

Сборка проекта в директорию build с предварительной проверкой стилей линтером Stylelint
